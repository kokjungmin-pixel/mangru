# 지표 정의와 손 계산 예시 (Data)

> 원본은 `docs/parts/4_Data_김지유.md` 의 B2다. 계산식은 B2에 적힌 그대로 옮겼고, 식을 바꿀 때는 PM과 상의한 뒤 이 문서와 손 계산 예시를 같이 고친다.
>
> **확인 기록:** 2026-11-14 김지유가 엑셀로 손 계산 예시를 직접 계산했고, B2에 적힌 값과 전부 일치했다(반올림 전 값 포함).

## 1. 준비 (한 분기의 보유 표)

1. `is_etf=True` 인 종목을 뺀다. 옵션·원금 행은 Frontend가 이미 뺐다.
2. 주가 `price = value_usd ÷ shares`. 전체 금액 `V = Σ value_usd`. 비중 `w = value_usd ÷ V`.
3. 시가총액 `mcap = price × shares_outstanding`. 규모 구간(`config.SIZE_BOUNDS_USD`):
   - 소형: `mcap < 20억 달러`
   - 중형: `20억 ≤ mcap < 100억`
   - 대형: `100억 ≤ mcap`
4. 업종: `sic` 앞 두 자리로 SIC 공식 대분류 10개 중 하나에 넣는다(`src/analysis/sectors.py` 한 곳에 둔다).

| SIC 앞 두 자리 | 업종 |
|---|---|
| 01~09 | 농림어업 |
| 10~14 | 광업 |
| 15~17 | 건설 |
| 20~39 | 제조 |
| 40~49 | 운송·통신·전기가스 |
| 50~51 | 도매 |
| 52~59 | 소매 |
| 60~67 | 금융·보험·부동산 |
| 70~89 | 서비스 |
| 91~99 | 공공·기타 |

5. 데이터 검사
   - 매핑률 = `issuer_cik` 가 있는 종목의 금액 합 ÷ V. `config.MIN_MAPPING_RATE`(0.95) 미만이면 업종·규모 지표는 계산하지 않고 `unavailable` 에 적는다.
   - 규모는 추가로, 시가총액 구간을 정할 수 있는 종목의 금액 합 ÷ V 가 `config.MIN_SIZE_COVERAGE`(0.90) 미만이면 `확인 불가`.
   - 구간을 정할 수 없는 종목: `shares_outstanding=None`, 또는 `shares_outstanding_partial=True` 인데 하한값으로 계산한 시가총액이 100억 달러 미만인 경우.
   - 기준을 넘으면 값을 못 찾은 종목은 "미분류"로 두고 비중 계산의 분모에는 남긴다.
   - 집중도·회전율은 종목 식별이 필요 없어 항상 계산한다.

## 2. 주식 분할 보정 (두 분기 모두 보유한 종목마다)

주가 변화 `c = price_now ÷ price_prev`.

1. 두 분기 모두 `shares_outstanding` 이 있으면 `k = so_now ÷ so_prev`. `k ≥ 1.4` 또는 `k ≤ 1/1.4` 이고 `0.7 ≤ c × k ≤ 1.4` 이면 **분할**로 본다 → `shares_prev × k`, `price_prev ÷ k` 로 맞춘다.
2. 1에 해당하지 않고 발행주식 수를 몰라 확인할 수 없는데 `c < 0.55` 또는 `c > 1.8` 이면 **분할 여부 확인 불가**로 본다 → 그 종목은 매매가 없었던 것으로 둔다(`shares_prev := shares_now`).
3. 보정하거나 제외한 종목은 `data_checks` 에 "분할 보정: XYZ ×2" / "가격 급변으로 매매 계산 제외: XYZ" 로 적는다.

상수는 `config` 의 `SPLIT_SO_RATIO`, `SPLIT_CAP_BAND`, `PRICE_JUMP_BAND`.

예: 2대1 분할이면 `k = 2`, 주가가 10달러 → 5.5달러면 `c = 0.55`, `c × k = 1.1` → 분할.

## 3. 매매 기준 변화 (`active_change`)

주가만 변해서 생긴 비중 변화를 빼고, 매매로 생긴 변화만 보기 위한 값이다.

```
passive 금액_i = (보정한) 직전 주식 수_i × 최신 주가_i        # 그대로 들고 있었다면
                 최신 분기에 없는 종목(전량 매도)은 최신 주가 대신 직전 주가를 쓴다
passive 비중_i = passive 금액_i ÷ Σ passive 금액
active_change(묶음) = Σ 실제 최신 비중 − Σ passive 비중       # 묶음 = 업종, 규모 구간, 상위 10종목
```

## 4. 지표별 정의

| 기준값 이름 | 계산 | 신호에 넣는 값 |
|---|---|---|
| `sector_shift` | 업종별 `active_change` 를 구해 절댓값이 가장 큰 업종 g를 고른다. 변화폭 = `\|active_change_g\|` | `metric="sector_weight:<g>"`, `before`·`after` = g의 실제 비중, `change = after − before`, `active_change` |
| `size_shift` | 소형·중형·대형별 `active_change` 중 절댓값이 가장 큰 구간. 변화폭 = 그 절댓값 | `metric="small_cap_weight"` 등, 위와 같음 |
| `concentration_change` | `top10(비중)` = 비중이 큰 10종목의 합(종목이 10개 미만이면 전부). 변화폭 = `\|top10(실제 최신 비중) − top10(passive 비중)\|` | `metric="top10_concentration"`, `before`·`after` = 실제 top10 |
| `turnover` | 종목별 `Δ = shares_now − (보정한) shares_prev`. 매수액 = `Σ max(Δ, 0) × price_now`, 매도액 = `Σ max(−Δ, 0) × price_prev`. `turnover = min(매수액, 매도액) ÷ ((V_prev + V_now) ÷ 2)`. 변화폭 = `turnover` 자체 | `metric="turnover"`, `after` = 이번 분기 회전율, `before` = 직전 분기 회전율, `active_change=None` |

`min(매수액, 매도액)` 을 쓰는 이유: 고객 자금이 들어오거나 나가서 생긴 매매를 빼고 "종목을 바꾼 정도"만 보기 위해서다.

## 5. 손 계산 예시 (이 숫자가 그대로 테스트가 된다)

### 입력

| 종목 | 직전 주식 수 | 직전 주가 | 직전 금액 | 최신 주식 수 | 최신 주가 | 최신 금액 |
|---|---|---|---|---|---|---|
| A | 100 | 10 | 1,000 | 100 | 12 | 1,200 |
| B | 50 | 20 | 1,000 | 25 | 20 | 500 |
| C | 0 | — | 0 | 10 | 40 | 400 |
| 합계 | | | 2,000 | | | 2,100 |

### 비중과 `active_change`

| 종목 | 실제 최신 비중 | passive 금액 | passive 비중 | `active_change` | 반올림 전 값 |
|---|---|---|---|---|---|
| A | 1,200 ÷ 2,100 = 57.1% | 100 × 12 = 1,200 | 1,200 ÷ 2,200 = 54.5% | +2.6%p | `0.0259740…` |
| B | 500 ÷ 2,100 = 23.8% | 50 × 20 = 1,000 | 1,000 ÷ 2,200 = 45.5% | −21.6%p | `−0.2164502…` |
| C | 400 ÷ 2,100 = 19% | 0 | 0% | +19%p | `0.1904762…` |
| 합계 | 100% | 2,200 | 100% | 0 | |

A는 사고팔지 않았는데 +2.6%p인 이유: B를 500 팔고 C를 400만 사서 전체 금액이 줄었기 때문이다. 비중은 상대값이라 생기는 효과이고 오류가 아니다.

### 회전율

- 매수액 = C 10주 × 40 = 400
- 매도액 = B 25주 × 20 = 500
- `min(400, 500) = 400`
- 평균 금액 = (2,000 + 2,100) ÷ 2 = 2,050
- 회전율 = 400 ÷ 2,050 = **19.5%** (반올림 전 `0.1951220…`)

### `size_shift` (A·B가 대형, C가 소형일 때)

- 소형 `active_change` = +19%p
- 대형 `active_change` = (57.1% + 23.8%) − 100% = −19%p
- `size_shift` = 19%. 절댓값이 같으므로 소형 → 중형 → 대형 순서에서 앞선 소형으로 신호를 낸다.

### 테스트 기준

`active_change`(A·B·C), 회전율, `size_shift` 가 위 반올림 전 값과 같아야 한다(허용 오차 1e-6).

## 6. 한계

- **체결 가격을 모른다.** 13F에는 분기 말 보유 내역만 있어 실제 매매 가격을 알 수 없다. 그래서 매매 금액과 `active_change` 는 분기 말 가격으로 근사한 값이다.
- **업종 분류가 거칠다.** SIC 대분류라 반도체와 제약이 둘 다 제조에 들어가고, 소프트웨어는 서비스에 들어간다.
- **일부 분할은 잡지 못한다.** 발행주식 수를 모르는 종목의 3대2 분할(`c ≈ 0.67`)은 분할로 판정되지 않는다.
