## 코드 판정 decide.py (2026-11-13)
- 무엇을 하는가: 심판 점수표로 변화별 설명됨·미설명을 정하고, 미설명 개수로 `유지 / 조건부 유지 / 해지 검토` 권고와 선택지 3개의 근거를 만든다.
- 어떻게 하는가: LLM 없이 코드 규칙으로 정한다. 유지 측이 1점(`EXPLAINED_MARGIN`) 이상 앞서야 설명됨이고, 미설명 0건은 유지·2건 이하는 조건부 유지·그 이상은 해지 검토다. 미설명이 모두 13F 신호면 조건부 유지로 내린다. 근거는 양측 논거·반증 조건 문장을 그대로 옮기고 끝에 `[signal_id]`를 붙인다.
- 한계: 기준값(1점, 2건)은 기획서에 숫자가 없어 정한 기본값이라 12/5 점검에서 다시 본다. 판정은 심판 점수를 그대로 믿으므로 점수의 질은 심판 프롬프트에 달려 있다.
