## LLM 호출 모듈 llm.py (2026-11-13)
- 무엇을 하는가: 모든 파트의 LLM 호출을 `call_llm` 하나로 받아 role(keep·terminate·judge·analyst)별 모델로 보내고, JSON 응답을 읽어 필요한 키가 있는지 검사한다.
- 어떻게 하는가: 형식이 틀리면 오류 내용을 붙여 1회 재요청하고, API 오류는 1초·2초 대기로 최대 3회 시도한다. 호출 수(`call_llm` 횟수 + 재요청, API 재시도는 제외)가 실행당 상한을 넘으면 멈추고, 실패하면 `LLMUnavailable` 로 알려 부르는 쪽이 `확인 불가` 로 처리한다. 요청마다 시각·모델·토큰·시간을 `logs/llm_calls.jsonl` 에 남기되 프롬프트·응답 본문은 남기지 않는다. `LLM_MOCK=1` 이면 계약 샘플에서 만든 고정 응답을 쓴다.
- 한계: 실제 API 호출(`_send_real`)은 API 키를 받은 뒤 구현한다. 지금은 mock으로만 돈다. API 오류는 종류를 가리지 않고 모두 재시도한다.
