## sec_get — SEC 요청 공용 함수 (2026-11-15)
- 무엇을 하는가: 모든 SEC 주소를 이 함수 하나로 받아 JSON 또는 원본 bytes로 돌려준다. 404나 끝내 실패하면 예외 없이 `None`.
- 어떻게 하는가: User-Agent `Mangru-Team <SEC_CONTACT_EMAIL>`, 요청 사이 0.2초, 3번 시도(1초·2초 대기), 받은 원본은 `data_cache/raw/http/` 에 저장해 같은 주소는 다시 요청하지 않는다.
- 한계: 저장본이 있으면 새로 받지 않으므로, 바뀌는 주소(공시 목록 등)를 갱신하려면 저장본을 지워야 한다.

## 13F 정보표 읽기·정리 — parse_infotable, clean_rows (2026-11-15)
- 무엇을 하는가: 13F 정보표 XML을 종목별 행으로 읽고, 옵션·원금 행을 빼고 같은 CUSIP을 합친다.
- 어떻게 하는가: 태그 앞의 네임스페이스를 `{*}` 경로로 무시하고 읽으며, 정리 규칙은 Frontend 문서 B3-5를 따른다.
- 한계: 정정본은 아래 apply_amendments 에서 처리한다.

## 13F 금액 단위 — to_usd (2026-11-21)
- 무엇을 하는가: 13F 금액을 달러로 통일한다. 2023-01-03 이전 제출분은 천 달러 단위라 ×1000.
- 어떻게 하는가: 제출일로 배수를 정하고, 변환 뒤 주가(금액÷주식 수) 중앙값이 $1~$1,000 밖이면 `notes` 용 문장을 돌려준다.
- 한계: 범위 밖이어도 값을 고치지 않고 기록만 한다(PM에게 알리는 것은 사람). 주식 수 0인 행은 주가 계산에서 뺀다.

## 데모 운용사 후보 정리 — scripts/collect_candidates.py (2026-11-15)
- 무엇을 하는가: 후보 운용사마다 13F 연속 분기 수, 종목 수, 예탁증서 비중, CRD, SEC 등록일을 SEC에서 받아 B2 조건표로 낸다.
- 어떻게 하는가: EDGAR submissions API, 최신 13F 정보표, IAPD 회사 상세 API를 `sec_get` 으로 부른다. 이 표로 Akre·Brown Capital·Warburg Pincus를 골랐다.
- 한계: 예탁증서 비중은 titleOfClass 글자로 추정한 값이고, 단일 전략 여부와 CIO 교체 보도는 사람이 따로 확인해야 한다.

## 13F 정정본 — amendment_type, apply_amendments (2026-11-21)
- 무엇을 하는가: 한 분기의 원본과 정정본(`13F-HR/A`)을 합쳐 최종 보유 종목을 만들고, 어떻게 처리했는지 `notes` 에 남긴다.
- 어떻게 하는가: 표지의 `amendmentType` 을 읽어 제출일 순으로 적용한다. 전체 대체(RESTATEMENT)는 바꿔 끼우고, 종목 추가(NEW HOLDINGS)는 이미 있는 CUSIP을 뺀 새 종목만 더한다(Akre 2024Q1 정정본이 원본 종목을 다시 적어서). 금액 단위는 공시마다 그 공시의 제출일로 맞춘 뒤 합친다.
- 한계: 정보표가 빈 전체 대체와 유형을 못 읽은 정정본은 건너뛰고 기록만 한다. 원본과 같은 CUSIP을 정정본에서 더 사들인 것처럼 적는 경우는 구분하지 못한다(아직 본 적 없음).

## 13F 분기 수집 — collect_13f (2026-11-21)
- 무엇을 하는가: 운용사 CIK를 넣으면 최신 14개 분기 13F를 SEC에서 받아 `QuarterHoldings` 목록(오래된 → 최신)과 처리 기록(`notes`), 확인 불가 항목을 돌려준다.
- 어떻게 하는가: submissions 목록에서 `13F-HR`·`13F-HR/A` 를 보고 기준일별로 묶고, 공시마다 정보표 읽기 → 정리 → 달러 변환을 한 뒤 정정본을 적용하고, 분기 말일로 Data의 `enrich_cusips` 를 불러 종목 정보를 붙인다. 표지 행 수와 읽은 행 수가 다르면 기록한다.
- 한계: 분기 안의 공시(원본·정정본)를 하나라도 못 받았거나 원본 없이 정정본만 남은 분기는 일부 종목만으로 만들지 않고 `확인 불가` 로 둔다. submissions 의 최근 1,000건(`filings.recent`)만 본다. 데모 2곳은 충분하지만 제출이 많은 대형 운용사는 옛 분기가 빠질 수 있다.
